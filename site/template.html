使い方

端末での手順（Galaxy A25）

  1. 端末を初期化（工場出荷状態へリセット）し、最初の「ようこそ」画面を表示する。
  2. 「ようこそ」画面の何もないところを6回すばやくタップすると、QR読み取りが始まる（カメラの許可を求められたら許可）。
  3. このページで作ったQRを読み取る。端末がWi-Fi（またはモバイルデータ）につながり、「初期設定ヘルパー」をダウンロードして管理設定が始まる。
  4. 初期設定は自動で一度だけ適用され、画面には何も出ずにAndroidのセットアップが続く。残りのセットアップ画面（Androidや機種側の必須画面）を進める。
  5. ホーム画面が出てしばらくすると「初期設定が完了しました」画面が自動で開く（開かない場合はアプリ一覧の「初期設定ヘルパー」を開く）。要確認の項目があれば後で設定アプリから直す。
  6. 「個人用端末へ切り替える」を1回押す。「個人用端末への切り替えが完了しました」と表示されたら完了。アプリはアンインストールしてよい。
  7. Googleアカウントは「設定 › アカウントとバックアップ › アカウントを管理」から手動で追加する。

QR読み取りで「ダウンロードできません」「チェックサムが一致しません」と出る場合は、Wi-Fi情報の誤り、またはAPKのURL・チェックサムの不一致です。このページで作り直してください。

管理の解除

手動で管理を解除する手順

  1. セットアップが終わってホーム画面が出ていることを確認する。
  2. アプリ一覧から「初期設定ヘルパー」を開く。
  3. 「個人用端末へ切り替える」を押す（セットアップ途中や古いQRの場合は、代わりに「このアプリによる端末管理を解除」→確認ボタンの経路がある）。
  4. アプリが管理権限の解除を読み戻して確認し、「個人用端末への切り替えが完了しました」と表示する。表示されない場合は端末を再起動してもう一度試す。
  5. ステータスバーに「この端末は管理されています」の表示が残るときだけ、手動で再起動する（アプリは自動再起動しません）。

解除には Android の DevicePolicyManager.clearDeviceOwnerApp を使います。この API は「テスト用途向け」と注記された非推奨 API ですが、Android 16（API 36）でも引き続き提供されており、アプリ自身が Device Owner を外せる唯一の公開手段です。一部のポリシーは残ることがあると Android の文書に書かれていますが、このアプリは端末に制限ポリシーを追加しないため、残るものはありません。どうしても解除できない場合は、端末の初期化で管理は外れます。

仕組み

安全面について

  • Wi-Fi情報はこのページの中（お使いのブラウザー）だけで処理し、サーバーへ送信・保存しません。URL・ログ・解析ツール・ブラウザーの保存領域にも残しません。
  • 「初期設定ヘルパー」はネットワーク権限を持たず、通信・情報収集・遠隔操作の機能はありません。Wi-Fiパスワードはアプリに保存しません（QRの内容はAndroidのセットアップが直接Wi-Fi設定に使います）。
  • 設定は初回に一度だけ適用し、アプリを開き直しても、再起動しても、更新しても自動では再適用しません。
  • セットアップ完了の確認は、端末内の一時的なジョブ（最長30分）で行います。完了前に切り替え画面を自動表示することはありません。
  • OS更新の制御、自動再起動、アプリの自動追加は行いません。
QRの中身（JSON）: 管理コンポーネント __COMPONENT__ ／ APK URL とチェックサム（SHA-256, URL-safe Base64）／ Wi-Fi情報 ／ PROVISIONING_LOCALE=ja_JP, PROVISIONING_TIME_ZONE=Asia/Tokyo, LEAVE_ALL_SYSTEM_APPS_ENABLED=true, ADMIN_EXTRAS_BUNDLE.show_personal_switch_after_setup=true。
